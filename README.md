# MD Capture

Chrome系ブラウザで開いたページを、レンダリング後の状態で Markdown＋メタ情報＋HTML の一式としてローカルに保存する拡張機能です。サイト別の処理は持たず、どのサイトでも同じ手順で動く汎用設計です。

保存されるもの（1ページにつき1フォルダ）:

- `page.md` … ページ全体のMarkdown（本文・全リンク・画像・表）
- `article.md` … 本文だけを抽出したMarkdown（記事系ページ向け）
- `meta.json` … URL・タイトル・metaタグ・OG・JSON-LD・全リンク一覧・画像一覧
- `page.html` … レンダリング後のHTML丸ごと（Markdown化で落ちた情報の掘り起こし用）

## 構成

- 拡張機能（MV3）: `manifest.json`、`background.js`、`content.js`、`lib/`
- ローカルコレクタ: `collector.py`（Python 3、標準ライブラリのみ。127.0.0.1:8765 で待ち受け、受け取った一式を `~/md-captures/<ホスト名>/<日時>-<タイトル>/` に保存します）

キャプチャした内容が外部に送信されることはありません。通信先は自分のマシンのコレクタ（127.0.0.1）だけです。

## セットアップ

1. ライブラリを取得します（第三者ライブラリは再配布せず、CDNから取得する形にしています）。

   ```sh
   lib/fetch-libs.sh
   ```

   - Turndown 7.2.0（MIT License）
   - Readability 0.6.0（Apache License 2.0）

2. コレクタを起動します。

   ```sh
   python3 collector.py
   ```

3. ブラウザの拡張機能ページで開発者モードを有効にし、「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選びます。

## 使い方

- 自動: URLの末尾に `#mdcapture` を付けてページを開く（スクロールで読み込まれるページは `#mdcapture=scroll`）
- 手動: ツールバーの拡張ボタンを押す

キャプチャ前にページの安定を待ちます（ロード完了＋DOMの静止＋表示テキスト量の安定）。ボット確認画面（「Just a moment」「Verify you are human」等の汎用パターン）は記録せず、本来の内容に切り替わるまで1秒間隔で再判定しながら最大120秒待ちます。切り替わらなかった場合は、記録せずに終了します（保存直前にも再判定します）。また、同じURLの短時間（30秒以内）の再保存は抑止されます（ツールバーボタンからの明示的な再取得は対象外）。

コレクタが起動していない場合は、Markdownファイルのダウンロードにフォールバックします。

## 取れる範囲と限界

- 取れる: DOMに存在するテキスト・リンク先・画像・表・メタ情報。ログイン済み／JS描画後の状態で取れるのがブラウザ内方式の強みです。
- 取れない: canvas描画の中身、画像の中の文字、閉じた shadow DOM の内側、クリックやホバーをしないと現れない状態、仮想スクロールで破棄された行。
- `page.html` が残るので、Markdownで落ちた情報は後から解析し直せます。

## 変更履歴

### 0.2.1

汎用キャプチャのバグ修正のみのリリースです。

- ボット確認画面を `possible_interstitial: true` の印付きで保存してしまう経路を廃止しました。確認画面の間は保存せず1秒間隔で再判定し、最大120秒待っても解けない場合は保存せずに終了します。保存直前にも再判定するガードを追加しました。
- ボット確認画面の検出を強化しました。チャレンジ基盤のDOMマーカー（`#challenge-form`、`challenges.cloudflare.com` の iframe、`challenge-platform` スクリプト）と、日本語のタイトル・文言（「しばらくお待ちください」「あなたが人間であることを確認」等）も対象にしました。
- ページ安定待ちの完了コールバックが2回発火し、同じページが二重に保存される問題を直しました（完了は1回限りとし、安全タイマーを解除します）。
- 同じURL（フラグメントを除いた形）について、30秒以内の再保存を抑止するようにしました。フラグメント付きURLの再読み込みで再発火するケースへの対策です。ツールバーボタンからの明示的な再取得は対象外です。

初回公開版。
